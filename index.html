How do we use this data?

The key difference is what happens when a space changes. Who has to update what, and where?

Option A

Upload the spreadsheet

The spreadsheet is uploaded to WordPress and re-uploaded as availability changes. Property pages are still updated by hand, as today.

  • Fastest to launch
  • Double the work to maintain: every change is made in the spreadsheet and on the property page
  • The chat and the property pages can disagree when one gets missed
Option B

Enter each space once in WordPress

A space is entered once in a WordPress form, with RSF, features, floor plan image and PDF. The site reads that one entry everywhere it’s shown.

What powers the search?

The difference is how a request is understood, and what it searches.

Option A

AI chatbot plugin

AI Engine Pro or WPBot Pro, set up to search our availability data. Built around a chat window.

  • Understands open-ended, conversational requests
  • Plugin updates maintained by the vendor
  • Some risk of unexpected or made-up answers unless tightly limited to our data
  • $70 to $200+ a year in licenses, plus AI usage fees
  • Needs CBRE approval of the AI vendor and a spending cap
Option B

Custom build

Custom code running on WordPress, reading the same data as the property pages. Can be a chat, a filter list, or both.

  • Searches the same data that updates the property pages, so results always match
  • Reads key words and answers only from the data: always factual, but less conversational
  • In-house maintenance may be needed down the line
  • Free: no license or AI usage fees

Recommendation

Launch the chat now, build the foundation alongside it

Start with an AI chatbot on the spreadsheet so visitors get the chat experience soon. In the background, set up the WordPress data so both work together, and we get the best of both.

  1. Now

    Gather the data

    Compile the clean availability spreadsheet from the site and brochures, with the brokers.

  2. When the data is ready

    Launch the AI chatbot

    Purchase the plugin and point it at the spreadsheet. Visitors get the chat experience right away.

  3. In the background

    Build the WordPress data

    Set up the custom fields and property-page embeds. Then switch the chatbot to read the same data, and the spreadsheet retires.
